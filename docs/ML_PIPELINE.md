# AI-NIDS Machine Learning Pipeline Document

## 1. Overview

The machine learning subsystem provides real-time threat classification. It takes tabular network flow features generated by Scapy and classifies them as `BENIGN` (0) or `ATTACK` (1).

---

## 2. Dataset & Training Parameters

- **Source Dataset**: CICIDS2017 (`Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv.parquet`).
- **Cleaned Data Size**: 216,387 records.
- **Features Used**: 10 statistical flow metrics.
- **Algorithm**: `RandomForestClassifier` (100 Trees, `random_state=42`, `class_weight='balanced'`).
- **Data Split**: 75% Train, 25% Test (Stratified).

---

## 3. Feature Compatibility Matrix

| Feature Index | Feature Name | CICIDS2017 Column Name | Live Scapy Extraction |
|---|---|---|---|
| 1 | Destination Port | `Destination Port` | `packet[TCP/UDP].dport` |
| 2 | Protocol | `Protocol` | `packet[IP].proto` |
| 3 | Flow Duration | `Flow Duration` | `(last_time - start_time) * 1e6` |
| 4 | Total Fwd Packets | `Total Fwd Packets` | Increment forward counter |
| 5 | Total Backward Packets | `Total Backward Packets` | Increment backward counter |
| 6 | Total Length of Fwd Packets | `Total Length of Fwd Packets` | Sum forward packet sizes |
| 7 | Total Length of Bwd Packets | `Total Length of Bwd Packets` | Sum backward packet sizes |
| 8 | Fwd Packet Length Mean | `Fwd Packet Length Mean` | `Fwd Bytes / Fwd Packets` |
| 9 | Bwd Packet Length Mean | `Bwd Packet Length Mean` | `Bwd Bytes / Bwd Packets` |
| 10 | Flow Bytes/s | `Flow Bytes/s` | `Total Bytes / Duration` |
| 11 | Flow Packets/s | `Flow Packets/s` | `Total Packets / Duration` |

---

## 4. Preprocessing Engine (`ml/preprocess.py`)

1. **Header Cleaning**: `.str.strip()` removes accidental whitespace in CSV columns.
2. **Type Coercion**: `pd.to_numeric(..., errors='coerce')` converts string inputs to floats.
3. **Median Imputation**: `MedianImputer` fits median values on training set $X_{\text{train}}$ and imputes NaNs.
4. **Label Binarization**:
   - `"BENIGN"` $\to 0$
   - `"ATTACK"` $\to 1$

## 6. Prediction Service (`ml/predict.py`)

`PredictionService` loads serialized Joblib binaries once upon application startup:
```python
self.model = joblib.load(MODEL_PATH)
self.feature_list = joblib.load(FEATURE_LIST_PATH)
preprocessing_info = joblib.load(PREPROCESSOR_PATH)
```

For each updated flow, `predict()` validates numeric types, orders features into the exact training sequence, computes probabilities using `predict_proba()`, and computes alert severity (`HIGH` if confidence $\ge 0.90$, else `MEDIUM`).
